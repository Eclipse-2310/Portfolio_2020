# Rehan Shaikh | 3D Interactive Portfolio

An interactive 3D portfolio for **Mohamad Rehan Bilal Shaikh**, B.Tech student in Artificial Intelligence & Machine Learning at St. John College of Engineering and Management (SJCEM), Palghar. Roll the ball around the world to explore projects, skills, and a timeline.

Built on [0xFloyd/Portfolio_2020](https://github.com/0xFloyd/Portfolio_2020) (MIT licensed) using [Three.js](https://github.com/mrdoob/three.js) and [Ammo.js](https://github.com/kripken/ammo.js).

## What's in the world

- **Projects**: CrowdDekho, College Management System (live on Vercel), FORM FITNESS, Capstone Project
- **Skills**: Python, C/C++, SQL, ML libraries (Scikit-learn, TensorFlow, NumPy, Pandas), Git and more
- **Timeline**: education, hackathons (VEXORA'26, Smart India Hackathon 2025) and certifications
- **Base44 apps**: MOVIExMANAICS, RoomieSplit, ScholarPulse, SpaceScope (billboards south of the start point)
- **Links**: GitHub, LinkedIn, Email

## Run locally

```bash
npm i
npm run dev      # dev server on localhost:8080
npm run build    # production bundle in /build
```

## Customising

Links live in `src/resources/textures.js` (`URL.linkedin` still needs your exact profile URL). Billboard and text images are in `src/jsm/`.
